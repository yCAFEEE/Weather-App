# ⛅ Weather App
An application that shows detailed, real-time weather information for a searched city. The backend was built using **Django** to access the **OpenWeather API** and send the data to the frontend, which was developed with **React**. The project was inspired by the [GeeksforGeeks Weather App with Django tutorial](https://www.geeksforgeeks.org/python/weather-app-using-django-python/) and the video [React Django Tutorial - Learn React Python Django In 1 Hour | For Beginners](https://www.youtube.com/watch?v=xldTxXtNiuk).

## 📚 Installation and Usage

### Dependencies
To run frontend or backend, you must have installed:
```
npm (10.8.2 or higher)
node (20.19.5 or higher)
python (3.12.3 or higher)
django (4.2.11 or higher)
```

To install the **frontend** dependencies, navigate to `client/` directory and run `npm install` command in the terminal.

### Usage
To start the **server**, navigate to `server/` directory and execute the command `python manage.py runserver` in the terminal or cmd. \
To run **frontend**, open the `client/` directory and execute the command `npm run dev` in the terminal or cmd.

## 🛠 Technologies Used
- Backend: Django (Python)
- Frontend: React (JavaScript)
- API: OpenWeather API
- Communication: REST API (JSON)
